# openSGX - Open Source SuperGrafx Motherboard Replica
![3D Rendering](https://github.com/Antipixel/openSGX/blob/main/Images/opensgx.png) 
![SGX Photo](https://github.com/Antipixel/openSGX/blob/main/Images/supergrafx-photo.jpg)

Things to keep in mind:
- I'm not an electrical engineer, only a hobbyist. As such, this design may have flaws and the only guarantee I can offer, is that I have designed this *to the best of my ability*.
- I received the donor motherboards used for this project in a plastic bag, as a few dozen fragments of shattered PCB. As a result, there was a little bit of guess work involved in the board dimensions/hole spacing and may not be 100% true to the original motherboard.
- Currently, many of the components are reused and you will need an original SuperGrafx from which to transfer the components to the replica board. I'm working on finding suitable replacements for as many components as is practical.
- There may be other revisions of the SuperGrafx motherboard that I am not aware of, and may not be compatible in some way with this replica board. If you come across this, please let me know!
